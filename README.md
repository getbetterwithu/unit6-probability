# unit6-probability — 경우의 수와 확률 비주얼 노벨 (Engine v2)

중학교 2학년 수학 6단원 **경우의 수와 확률** 복습 및 탐구용 차세대 웹 인터랙티브 비주얼 노벨.

## 1. 개요
- **단원**: 중2 수학 6단원 (6-1 경우의 수 ~ 6-4 확률의 계산)
- **세계관**: 피타고라스 학당 3부작 (4단원 사각형 → 5단원 닮음 → 6단원 확률)
- **아키텍처**: Engine v2 (모듈 분리형 경량 브라우저 런타임)
  - `engine/`: 범용 대사 엔진, 2.5D 카메라 및 연출 레이어, 수학 위젯 인터페이스
  - `widgets/`: 주사위·동전 대수의 법칙 시뮬레이터, 동적 수형도(나뭇가지그림) 작도기
  - `data/`: 씬 스크립트(`scenario.js`), 교과서 기반 문제 데이터(`problems.js`)

## 2. 주요 기능
- **동적 확률 실험실**: 대수의 법칙(10~1,000회 연속 시뮬레이션) 실시간 상대도수 수렴 그래프
- **직관적 수형도 인터랙션**: 합의 법칙과 곱의 법칙을 시각적 경로 연결로 추론
- **감각적 연출(Juice & Polish)**: 화면 진동(Shake), 집중선, 타자기 블립 사운드, 인물 호흡 효과
- **크롬북 터치 최적화**: 반응형 캔버스 필기장 및 학습 결과 PDF 리포트 생성
